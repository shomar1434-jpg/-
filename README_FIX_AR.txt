تصحيح عام نهائي لثبات الجلسات وتوحيد عائلات الأدوار — RL143
التاريخ: 2026-09-13

السبب المؤكد:
آخر حزمة خاصة بالابتدائية السابعة عشر ببيشة أعادت في platform-cloud-session.js مطابقة دور العضوية مع دور الجلسة نصياً.
مثال: manager مقابل principal أو school_manager كان يرفض العضوية الصحيحة رغم أنها نفس عائلة الدور، فيظهر VERIFIED_MEMBERSHIP_MISSING ثم قد تعيد الصفحة المستخدم إلى تسجيل الدخول عند فتح قسم محمي.

التصحيح العام:
- توحيد الدور في verifyAccess بواسطة canonicalRole قبل مطابقة العضوية.
- school_id و user_id يظلان شرطين صارمين ولا يوجد أي تجاوز بين المدارس.
- توسيع بدائل الأدوار التاريخية المتكافئة: manager/principal/school_manager/school-manager وغيرها، وكذلك بدائل الموجه الطلابي والصحي.
- لا تغيير في بيانات المدارس أو المستخدمين أو العضويات.
- لا تغيير في manager.html؛ بوابة المدير الحالية تحتفظ بآلية ensure + إعادة المحاولة للأخطاء العابرة.
- لا تعديل Edge Function مطلوب: platform-session المنشور حالياً (v36) يحتوي canonicalRole ويصدر الدور القانوني الموحد، ويُنشئ جلسة التجديد البديلة قبل إلغاء القديمة.

التعميم:
الملف platform-cloud-session.js مشترك بين صفحات الأدوار، لذلك هذا التصحيح عام لجميع المدارس وليس خاصاً بمدرسة بعينها.

الملف المطلوب رفعه:
