تحديث سجلات الوكيل - المرحلة A

تم تنفيذ الآتي:
1) استكمال سجلات وكيل الشؤون التعليمية.
2) استكمال سجلات وكيل الشؤون المدرسية.
3) إعادة تصنيف قائمة سجلات الوكيل داخل الواجهة إلى:
   - وكيل الشؤون التعليمية
   - وكيل الشؤون المدرسية
   - السجلات المشتركة
4) ربط كل سجل بمعرف مجلد أرشيف مطابق له.
5) تحديث أرشيف السجلات داخل قسم الوكيل ليعرض المجلدات بنفس التصنيف:
   - أرشيف الشؤون التعليمية
   - أرشيف الشؤون المدرسية
   - الأرشيف المشترك
6) تجهيز حقول category و categoryLabel و folderName عند الحفظ حتى تصبح جاهزة لاحقًا لمرحلة فلترة السجلات حسب تصنيف الوكيل من حساب المدير.

ملاحظة:
لم يتم تفعيل صلاحيات الوكلاء أو تصنيف المستخدمين في هذه المرحلة؛ العمل محصور في استكمال السجلات وتصنيفها وربطها بالأرشيف.
