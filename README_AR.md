# RL182 — تصحيح تكليف الدور الكامل للوكيل

## الخطأ

عند تكليف مستخدم بدور كامل لوكيل الشؤون التعليمية أو المدرسية أو شؤون الطلاب، كانت وظيفة `platform-tasks` تمرر مالك بوابة الدور (`delegated_roles`) إلى فاحص سجلات الوكيل. السجلات الفعلية مسجلة بمالك `agent`، ولذلك كانت الوظيفة ترفض سجلًا صحيحًا برسالة مثل:

`تعذر التحقق من السجل الأصلي المحدد: academic_affairs/edu-18c0e8ffd9`

## التصحيح

- فصل هوية بوابة الدور عن ملكية سجلات الدور.
- تكليف وكيل الشؤون التعليمية يقبل فقط سجلات `academic_affairs`.
- تكليف وكيل الشؤون المدرسية يقبل فقط سجلات `school_operations`.
- تكليف وكيل شؤون الطلاب يقبل فقط سجلات `student_affairs`.
- يستمر التحقق من أن المستخدم المكلف هو صاحب التكليف الفعلي داخل المدرسة نفسها.
- يبقى الدور الأساسي للمستخدم دون تغيير، وتكون صلاحية الدور الكامل مؤقتة ومرتبطة بالتكليف النشط.
- لا يتم حذف أو تعديل أي تكليف أو سجل سابق.

## طريقة الرفع والنشر

1. ارفع محتويات هذه الحزمة إلى جذر مستودع GitHub مع الاستبدال.
2. تأكد من وجود الملف:
   `.github/workflows/deploy-supabase-functions.yml`
3. بعد الرفع سيعمل الـworkflow تلقائيًا لأن مساره يشمل:
   `supabase/functions/**`
4. انتظر نجاح مهمة **Deploy Supabase Edge Functions** قبل التجربة.

## التحقق بعد النشر

1. افتح مركز التكليفات بحساب المدير.
2. أنشئ تكليفًا من نوع «تكليف دور كامل».
3. جرّب الأدوار الثلاثة كلٌ على حدة: الشؤون التعليمية، الشؤون المدرسية، شؤون الطلاب.
4. افتح حساب المكلف، ثم افتح بوابة الدور من مركز تكليفاته.
5. تحقق من ظهور سجلات الوكالة الصحيحة فقط، وأن فتح السجل وحفظه يعملان دون رسالة المطابقة السابقة.

## الملفات المهمة في هذا الإصدار

- `supabase/functions/platform-tasks/index.ts` — التصحيح الخادمي الأساسي.
- `.github/workflows/deploy-supabase-functions.yml` — مسار النشر المركزي المعتمد.
- بقية الملفات هي الحزمة التراكمية لتصحيحات بحرة السابقة.
