# RL233 — توافق تفويض الأدوار

- يضيف توافقاً غير هدّام بين تكليفات `platform-tasks` القديمة وبوابة `platform-delegation` الحالية.
- لا يحذف أو يعدّل أي تكليف أو شاهد أو حساب.
- يحافظ على عزل المدرسة والتحقق من صاحب التكليف وحالته وتاريخ بدايته.
- يشمل: الموجه الطلابي، الموجه الصحي، رائد النشاط، معلمة رياض الأطفال، والموظف الإداري.

## بوابات التحقق

1. التكليف القديم النشط يظهر لصاحبه ويفتح القسم الصحيح.
2. التكليف الحديث يستمر بالعمل دون تغيير.
3. مستخدم آخر أو مدرسة أخرى لا يستطيعان الفتح.
4. التكليف المحذوف أو غير النشط أو غير المبدوء لا يمنح وصولاً.
5. لا توجد أي كتابة أو ترحيل لبيانات المدارس.

## النشر

يجب تحديث مسار GitHub لنشر الدالة في نفس التغيير قبل تفعيلها إنتاجياً.
