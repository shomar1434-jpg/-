تصحيح RL151 — توحيد جلسة المدارس المستقلة مع مسار المدرسة التجريبية

السبب الجذري المكتشف:
- school-login.html كان يسمح بفتح واجهة المدرسة إذا نجح التحقق المحلي من الحساب حتى عند فشل إنشاء platform-session السحابية (sessionCompatFallback).
- المدرسة التجريبية تعمل عبر platform-session فعلية، بينما مدرسة بيشة أمكنها المرور عبر المسار التوافقي المحلي؛ لذلك ظهرت واجهة المدير بلا x-platform-session ثم أنشأت الصفحات الداخلية طبقات تحقق إضافية ورسائل SESSION_MISSING.

التصحيح:
1) منع أي دخول لمدرسة مستقلة بدون platform-session خادمية ناجحة.
2) إزالة الاعتماد على sessionCompatFallback كمسار تفويض.
3) مركز المعلومات يعتمد جلسة cloud الواحدة فقط؛ لا ينشئ طبقة membership تحقق ثانية قبل العرض. Edge Functions نفسها تتحقق من school_id والدور.
4) متابعة التقويم تستخدم الجلسة نفسها، وEdge Function يفرض manager server-side.
5) إذا كانت الجلسة مفقودة/منتهية فعلاً، تعاد الصفحة إلى دخول المدرسة بدل إبقاء واجهة محلية منفصلة عن السحابة.

الأثر:
- التغيير مشترك لجميع المدارس المستقلة، بلا استثناء School ID أو اسم مدرسة.
- لا تعديل قاعدة بيانات ولا حذف بيانات أو ملفات.
- لا Edge Function جديد ولا تعديل Workflow مطلوب.
