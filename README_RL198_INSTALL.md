# RL198 — حزمة تصحيح توجيه السجلات فقط

هذه حزمة فرق صغيرة وليست نسخة كاملة من المنصة.

## مضمون التصحيح

- فتح السجل المطابق للاسم الموجود في التكليف.
- تقديم المسار القانوني الحالي على `route_url` التاريخي.
- معالجة التكليفات السابقة وقت الفتح دون حذفها.
- تحديث قاموس السجلات ومنع استخدام نسخته القديمة من ذاكرة المتصفح.

## التركيب

فك الضغط في جذر المستودع مع السماح باستبدال الملفات المطابقة فقط. لا تحذف أو تستبدل أي مجلد آخر.

تعدد صفحات HTML داخل الحزمة سببه أن كل صفحة مرتبطة بالقاموس تلقت رقم الإصدار الجديد فقط؛ وهي ليست نسخة كاملة من المنصة.

هذه الحزمة لا تحتوي تصحيح دخول المدارس RL199، الذي يبقى في حزمة مستقلة.
