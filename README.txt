تطوير شامل — متابعة الخطط الفصلية للأدوار المرتبطة بالمدير
التاريخ: 2026-09-11

القاعدة الجديدة:
- الموجه الصحي + الموجه الطلابي + رائد النشاط: الخطة الفصلية فقط مرتبطة بالمدير، ولا يظهر لهم قسم الأعمال الأسبوعية المرتبط بالوكيل.
- معلمة رياض الأطفال: تحتفظ بقسم الأعمال الأسبوعية المرتبط بالوكيل، وتعمل الخطة الفصلية بنفس آلية المدير الجديدة.

دورة العمل:
1) مسؤول الخطة يحرر أعمال كل أسبوع ويرسل خطة الأسبوع للمدير.
2) المدير يعاين الخطة ويعتمدها أو يعيدها للتعديل.
3) بعد الاعتماد، يرفع المسؤول نهاية الأسبوع شواهد التنفيذ.
4) مصادر الشاهد: رفع ملفات متعددة، مكتبة قسم صاحب الحساب، رابط خارجي.
5) المدير يجب أن يعاين جميع الشواهد قبل ظهور خيارات التقييم.
6) مستويات التقييم: منفذ بمستوى عالي / متوسط / منخفض.
7) صفحة متابعة الخطط الفصلية لدى المدير تعرض ملخصًا تنفيذيًا مستقلاً لكل قسم.

النشر:
1) ارفع الملفات بنفس المسارات.
2) نفذ migration مرة واحدة في Supabase SQL Editor.
3) platform-core موجود مسبقًا داخل workflow المركزي deploy-supabase-functions.yml، لذلك سيُنشر تلقائيًا عند رفع index.ts ولا توجد إضافة Workflow جديدة مطلوبة.
4) بعد نجاح GitHub Actions نفذ تحديثًا قسريًا للمتصفح.

ملاحظات حماية:
- التغييرات في قاعدة البيانات إضافية فقط ولا تحذف بيانات سابقة.
- evidence_file_id القديم محفوظ للتوافق، وأضيف evidence_items للشواهد المتعددة.
- اختيار مكتبة القسم يتحقق خادميًا من أن الملف مملوك للمستخدم الحالي داخل نفس المدرسة.
- عزل school_id محفوظ في جميع عمليات الخطة والمراجعة.
