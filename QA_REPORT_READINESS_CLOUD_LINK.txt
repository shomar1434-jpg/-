تقرير فحص ربط قسم الجاهزية بالحفظ السحابي
التاريخ: 2026-07-28

نطاق التعديل:
- school_readiness.html فقط من ملفات المنصة التشغيلية.
- لم يتم تعديل أي قسم آخر أو ملف اتصال مركزي.

المنفذ:
1. تحميل خطة الجاهزية حسب school_id والعام الدراسي والفصل الأول من جدول school_readiness_plans.
2. إنشاء الخطة تلقائياً عند عدم وجود سجل سابق.
3. حفظ تلقائي سحابي مؤجل Debounce بعد التعديلات، مع منع تضارب طلبات الحفظ المتزامنة.
4. استمرار LocalStorage كنسخة احتياطية عند انقطاع الاتصال أو فشل Supabase.
5. قراءة school_id من مفاتيح جلسة المنصة الحالية دون قيمة ثابتة.
6. ربط created_by وupdated_by بمعرف المستخدم الحالي عند توفر UUID صالح.
7. مؤشر مرئي لحالة: التحميل، الحفظ، النجاح، الخطأ، أو الحفظ المحلي المؤقت.
8. استيراد النسخة الاحتياطية أصبح يحفظ محلياً وسحابياً دون إعادة تحميل الصفحة.
9. المحافظة على مزامنة بيانات إعدادات المدير مع قسم الجاهزية.
10. لم يتم تغيير رفع ملفات الشواهد؛ ما زالت الملفات محلية في IndexedDB إلى حين إنشاء وربط Storage Bucket، بينما تفاصيل المهام محفوظة داخل readiness_data.

الفحوص:
- فحص JavaScript عبر node --check: ناجح.
- أسماء الجداول متوافقة مع الجداول المنشأة في Supabase.
- لا تعديل على supabase-bridge.js أو أقسام المنصة الأخرى.
