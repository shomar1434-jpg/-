RL102 — جدول الأولويات التفاعلي

الملف المعدل فقط: self_evaluation_records.html

التغييرات:
- المجال الأساسي أصبح قائمة منسدلة.
- مستوى الأولوية أصبح قائمة منسدلة.
- مبررات الاختيار والتقييم أصبحت مساحة نص متعددة الأسطر قابلة للتعبئة.
- الأولوية/الإجراء المتخذ بالخطة أصبحت مساحة نص متعددة الأسطر قابلة للتعبئة.
- إضافة زر لإضافة سطر جديد وزر حذف لكل سطر.
- عند الأرشفة/الطباعة تتحول الحقول إلى نص ثابت فقط لمنع التراكب.
- لا تعديل على Supabase أو التسجيل أو روابط الدخول أو Workflow.
