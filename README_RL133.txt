RL133 — إعادة قسم تحليل نتائج القدرات والتحصيلي للمدارس الثانوية

الملفات المعدلة فقط:
1) manager.html
2) qat_results_analysis.html (قسم مستقل جديد مبني على النموذج المرفوع)

ما تم:
- إضافة بطاقة أيقونية مستقلة في واجهة المدير باسم «تحليل نتائج القدرات والتحصيلي».
- إظهار البطاقة للمرحلة الثانوية بالاعتماد على الهيكل الدراسي السحابي/مرآة مركز المعلومات، مع السماح لمدير النظام برؤيتها للتهيئة.
- فتح القسم Full Page مع زر عودة واضح لواجهة المدير.
- الإبقاء على منطقة الاستيراد الموجودة في النموذج.
- تطبيق طبقة فتح وقراءة PDF المثبتة في بطاقة نافس: PDF.js + normalizeWhitespace + قراءة جميع الصفحات أولًا.
- تمرير النص/الإحداثيات بعد ذلك إلى محلل القدرات والتحصيلي المتخصص بدل Parser نافس.
- إضافة active_school_scope + school_isolation_guard + platform-cloud-session + platform-state-engine.
- حفظ آخر تحليل سحابيًا تحت school scope، مع تحقق من تطابق schoolId.
- جعل سجل اللقطات المحلي school-scoped بدل المفتاح العام qat_history لمنع تداخل المدارس.

لم يتم تعديل:
- nafs_results_analysis.html

- أي Edge Function أو قاعدة بيانات
- بقية بطاقات المدير

يجب اختبار بطاقة PDF حقيقية للقدرات/التحصيلي بعد الرفع؛ الفحص المحلي يؤكد سلامة البنية والـ JavaScript، أما دقة استخراج بطاقة بعينها فتحتاج البطاقة الفعلية نفسها.
