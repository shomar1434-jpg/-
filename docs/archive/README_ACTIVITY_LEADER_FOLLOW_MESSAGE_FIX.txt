تم تصحيح سبب عدم ظهور رسالة المتابعة في رائد النشاط.
السبب: رابط المتابعة كان يحتوي direct=1 و loginMode=direct، وسكربت رائد النشاط كان يعتبر ذلك دخولًا مباشرًا فيلغي وضع المتابعة رغم وجود follow=1 و readonly=1.
تم تعديل الشرط بحيث تكون علامات المتابعة الصريحة هي الأعلى أولوية.
كما تم جعل رسالة المتابعة ثابتة ولا تختفي بعد ثوانٍ.
