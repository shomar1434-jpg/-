# تصحيح ثبات قوائم الأسماء والأدوار — RL167

يعالج هذا الإصدار اختفاء القائمة المنسدلة فور فتحها في الحقول المرتبطة بمركز المعلومات.

## نطاق التصحيح

- الخطة التشغيلية التفاعلية.
- المجالس واللجان والفرق.
- سجلات المدير.
- سجلات الوكيل.
- سجلات التقويم الذاتي.

## السلوك بعد التصحيح

- تبقى قائمة الأسماء أو الأدوار ظاهرة أثناء البحث والاختيار.
- تختفي القائمة بعد اختيار العنصر أو النقر خارج الحقل وفق سلوك المتصفح الطبيعي.
- لا يعاد إنشاء خيارات القائمة إلا عند تغير بيانات مركز المعلومات فعلًا.
- يستمر تعبئة الدور أو المسمى الوظيفي والبيانات المرتبطة بعد اختيار الاسم.

## طريقة الرفع

ارفع الملفات الخمسة إلى جذر المنصة مع استبدال النسخ الموجودة، مع الحفاظ على أسماء الملفات ومساراتها كما هي. لا يحتاج هذا التصحيح إلى SQL أو ترحيل قاعدة بيانات أو نشر Supabase Edge Functions.
