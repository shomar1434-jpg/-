تم إصلاح الخطأ:
saveUnifiedUserStores is not defined

السبب:
ملف index-app.js كان يستدعي دالة saveUnifiedUserStores عند حفظ المدارس/المستخدمين، لكنها غير معرفة داخل نفس النطاق بعد تعديلات Supabase.

الإصلاح:
- إضافة الدالة داخل نطاق index-app.js.
- تحديث حفظ المدير المحلي بحيث يدعم نفس البريد المرتبط بعدة مدارس.
- حفظ المستخدمين في المخازن المحلية الثلاثة المتوافقة مع المنصة.
