# التصحيح RL169 — ثبات قوائم مركز المعلومات

## ما تم تصحيحه

- استبدال قوائم الاقتراحات الأصلية غير المستقرة (`datalist`) بقائمة اختيار ثابتة مشتركة تحاكي آلية مركز القرارات والتكليفات.
- تبقى القائمة مفتوحة أثناء البحث والتمرير، وتغلق فقط بعد الاختيار أو الضغط خارجها أو مفتاح `Escape`.
- دعم البحث المباشر، الأسهم، مفتاح `Enter`، اللمس، والنوافذ الداخلية (`iframe`).
- استمرار جلب الأسماء من مركز المعلومات ضمن المدرسة والعام الدراسي الحاليين.
- استمرار تعبئة المسمى الوظيفي تلقائياً للموظفين، وبيانات المرحلة والصف والشعبة/الفصل والمسار للطلاب.
- منع مراقب تغييرات الصفحة من إعادة بناء القائمة أو إغلاقها أثناء الاستخدام.
- منع تهيئة المصدر أكثر من مرة إذا حمّلته الصفحة مرتين.
- تحديث رقم نسخة الملف في جميع الصفحات التي تستخدمه لكسر ذاكرة المتصفح المؤقتة.

## الملفات المطلوب رفعها

ارفع جميع الملفات الموجودة داخل الحزمة إلى جذر المستودع مع الحفاظ على أسمائها. لا يتطلب التصحيح SQL أو Edge Function أو تعديل Workflow.

## التحقق بعد النشر

1. افتح الخطة التشغيلية أو أحد السجلات.
2. اضغط حقل الاسم أو الدور/المسمى الوظيفي.
3. تأكد أن القائمة تبقى مفتوحة أثناء التمرير.
4. اختر اسماً وتأكد من إغلاق القائمة وتعبئة البيانات المرتبطة.
5. نفذ تحديثاً إجبارياً للصفحة مرة واحدة (`Ctrl+F5`) إذا كانت الصفحة مفتوحة قبل النشر.
