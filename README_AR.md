# RL188 — معالجة تعليق صفحات الدخول وتشخيص الأخطاء

تتضمن الحزمة جميع ملفات RL187، وتضيف `school-login.html` و`index-app.js` و`index.html`.

- تحدد صفحة دخول المدرسة مهلة انتظار لقراءة المدرسة والحساب وإنشاء الجلسة، ثم تعيد زر الدخول إلى حالته الطبيعية وتعرض سبب الخطأ. تمنع النقرات المتزامنة على الدخول.
- تحدد واجهة مدير النظام مهلة للاتصال وتفرق بين رفض بيانات الدخول الفعلي وانقطاع خدمة المصادقة. تعيد تفعيل الزر بعد الفشل.
- يحدث `index.html` رقم نسخة `index-app.js` لكي يجلب المتصفح ملف الدخول المصحح بعد نشر GitHub Pages.
- تصحح واجهتا أعذار الغياب قراءة `supabaseUrl` و`anonKey` من إعداد الاتصال الفعلي؛ كانت نسخة RL187 تقرأ `url` غير الموجود، وقد تعطل إنشاء رابط العذر أو فتحه.
- لم تتغير هويات المستخدمين، كلمات مرورهم، أو روابط المدارس في قاعدة البيانات.

**تشخيص الخدمة:** مشروع Supabase ظهر بحالة `ACTIVE_HEALTHY`، لكن استعلام قراءة عبر موصل Supabase انتهى برسالة `Connection terminated due to connection timeout`. هذه ملاحظة عن الاتصال أثناء الفحص وليست إثباتًا نهائيًا لعطل قاعدة البيانات لدى جميع المستخدمين. لا يمكن تأكيد نجاح الدخول دون اختبار بحساب مخوّل بعد رفع التصحيح.

ارفع محتويات المجلد إلى جذر المستودع مع الحفاظ على المسارات. ملفات الواجهة تعمل بعد نشر GitHub Pages وتحديث الصفحة تحديثًا قسريًا. تحتوي الحزمة أيضًا على وظائف Supabase السابقة وملف Workflow المركزي.

# RL187 — تصحيح بوابة ولي الأمر وأعذار الغياب

هذه حزمة تراكمية تتضمن تصحيحات RL186 السابقة، مع إضافة تصحيحات شؤون الطلاب التالية:

- التحقق في بوابة ولي الأمر بآخر 4 أرقام من الجوال فقط، دون اشتراط إدخال اسم ولي الأمر.
- إظهار اسم الطالب/الطالبة وتاريخ إرسال المعاملة قبل التحقق.
- منع إظهار بريد الوكيل أو اسم الدخول في رسالة واتساب.
- دعم مسميات مثل «وكيل شؤون الطلاب الأول» بدون إضعاف عزل المدرسة.
- إصلاح إنشاء روابط أعذار الغياب، مع استعادة الجلسة مرة واحدة عند انتهائها وإظهار رسالة الخطأ الحقيقية.
- لا يتم حذف أو تغيير الروابط والمعاملات السابقة.

## الرفع

ارفع محتويات المجلد إلى جذر المستودع مع الحفاظ على المسارات. تغيير ملفي Edge Functions سيشغّل Workflow المرفق تلقائيًا على `main`.

## التحقق

بعد الرفع شغّل:

```bash
node verify_rl187.mjs
```
