تم تحويل النظام إلى Manual Docking Workspace:
- لا يوجد اختفاء تلقائي ولا ومضات مستمرة.
- تظهر أزرار تحكم ثابتة أسفل اليمين:
  علوي: طي/إظهار الشريط العلوي.
  جانبي: طي/إظهار الشريط الجانبي.
  سفلي: طي/إظهار الشريط السفلي.
  تركيز: إخفاء الأدوات لزيادة مساحة العمل.
- يتم حفظ حالة الطي والتركيز في localStorage.
- لا يتأثر وضع الطباعة أو النوافذ المنبثقة.
