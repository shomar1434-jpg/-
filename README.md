# منصة الإدارة المدرسية الذكية

منصة مدرسية لإدارة أعمال المدرسة وأقسامها التشغيلية، تشمل المدير، الوكيل، المعلم، الموجه/الموجهة الطلابية، رائد النشاط، وإدارة المدارس المستقلة.

## الأقسام الرئيسية

- قسم المدير
- قسم الوكيل
- قسم المعلم
- قسم الموجه/الموجهة الطلابية
- قسم رائد النشاط
- إدارة المدارس المستقلة
- التقويم الخارجي والأرشيف المؤسسي

## ملاحظات تشغيل

- الملف مهيأ للرفع على GitHub Pages بوجود `.nojekyll`.
- لا تعتمد ملفات التوثيق القديمة على تشغيل المنصة.
- تم نقل ملفات التوثيق والتصحيحات القديمة إلى `docs/archive` للاحتفاظ بها دون تشتيت جذر المشروع.

## النسخة

راجع ملف `VERSION.md` لمعرفة الإصدار وآخر التحديثات.


## ترقية هوية Microsoft للاجتماعات
شغّل `SUPABASE_MICROSOFT_OBJECT_ID_UPGRADE.sql` مرة واحدة بعد ترقية البريد. تصبح مطابقة حضور Teams بالأولوية لمعرف Microsoft Object ID ثم البريد الرسمي.
