تصحيح فتح واجهة الموجه الصحي عند الدخول بتكليف دور كامل — 2026-09-11

الملف المعدل فقط:
- health_advisor.html

السبب:
واجهة الموجه الصحي تحتوي بوابة ترحيب قديمة يعيد window.onload إظهارها بعد نجاح التحقق من تفويض الدور، فتظهر الخلفية فقط ويتوقف الدخول قبل لوحة القسم.

التصحيح:
- عند الدخول الطبيعي: تبقى بوابة الترحيب كما هي.
- عند delegated_role=1: لا يتم فتح لوحة القسم إلا بعد وجود سياق تفويض موثق أنشأه platform-cloud-session بعد تحقق platform-tasks.
- لا يعتمد التصحيح على باراميتر الرابط وحده.
- لا يغير الدور الأساسي ولا school_id ولا يعطل عزل المدارس.
- لا SQL ولا Edge Function جديدة ولا تعديل workflow مطلوب.
