تمت إعادة عناصر داشبورد المتابعة السابقة كما كانت:
- المساعد الذكي للأداء القيادي ورسائل التذكير.
- إجمالي التقارير المنجزة.
- شاشة عناصر القيادة المتحركة.
- تفاصيل العناصر والمستهدفات.

مع الإبقاء على الأقسام التحليلية الجديدة داخل نفس الداشبورد كبطاقات دخول مستقلة:
- لوحة التحليل العامة.
- تحليل أداء العاملين.
- تحليل الأسابيع.
- آلية التنفيذ الأسبوعية.
- التنبيهات الذكية.
