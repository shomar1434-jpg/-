تم تنفيذ خيار B: نظام الملف الشخصي المتكامل لكل مستخدم في المدرسة المستقلة.

المضافات:
1- ملف user-profile-engine.js كطبقة مستقلة لا تغيّر بنية ملفات المنصة الأصلية.
2- ربط النظام بصفحات الأقسام الأساسية:
   manager.html
   agent.html
   teacher.html
   student_advisor.html
   activity_leader.html
3- إضافة بطاقة/زر الملف الشخصي داخل لوحة القسم إن وجدت.
4- إضافة زر عائم ثابت باسم الملف الشخصي لضمان الوصول للنظام من أي قسم.
5- لكل مستخدم:
   - صورة شخصية.
   - الاسم.
   - المسمى الوظيفي.
   - البريد الإلكتروني.
   - الجوال اختياري.
   - نبذة مختصرة.
   - QR Code خاص بالملف.
   - بطاقة تعريف قابلة للطباعة.
   - مؤشرات أداء تسحب من التخزين المحلي حسب التقارير والسجلات ومحاضر الاجتماعات.
6- المدير يستطيع فتح ملفات مستخدمي المدرسة، وبقية الأدوار تفتح ملف المستخدم الحالي فقط.

ملاحظة:
QR Code يستخدم رابط توليد خارجي لعرض QR قابل للمسح عند وجود اتصال إنترنت، مع حفظ كامل بيانات الملف داخل localStorage للمدرسة المستقلة.
