# منصة الإدارة المدرسية الذكية

منصة مدرسية لإدارة أعمال المدرسة وأقسامها التشغيلية، تشمل المدير، الوكيل، المعلم، الموجه الطلابي، رائد النشاط، وإدارة المدارس المستقلة.

## الأقسام الرئيسية

- قسم المدير
- قسم الوكيل
- قسم المعلم
- قسم الموجه الطلابي
- قسم رائد النشاط
- إدارة المدارس المستقلة
- التقويم الخارجي والأرشيف المؤسسي

## ملاحظات تشغيل

- الملف مهيأ للرفع على GitHub Pages بوجود `.nojekyll`.
- لا تعتمد ملفات التوثيق القديمة على تشغيل المنصة.
- تم نقل ملفات التوثيق والتصحيحات القديمة إلى `docs/archive` للاحتفاظ بها دون تشتيت جذر المشروع.

## النسخة

راجع ملف `VERSION.md` لمعرفة الإصدار وآخر التحديثات.
