- يحدد المجال الأقل أداء تلقائيًا أو يسمح باختياره يدويًا.
- يقرأ مؤشرات SSPI وتحليل الأقسام والعاملين.
- يولد خطة تحسين كاملة قابلة للطباعة والحفظ PDF.
