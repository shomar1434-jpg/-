التصحيح الأول — سجل المعلم الشامل
الملف المعدل فقط: teacher_comprehensive_record.html

- استيراد المرحلة من مركز المعلومات ومطابقتها مع قائمة المرحلة في سجل المعلم.
- توحيد اختلافات تسمية المرحلة مثل: رياض أطفال / رياض الأطفال.
- بناء التسلسل: المرحلة ← الصف ← الشعبة ← الطلاب.
- إذا كانت المدرسة ذات مرحلة واحدة يتم تحديد المرحلة تلقائياً.
- إذا كانت متعددة المراحل تظهر المراحل المستوردة للاختيار.
- المادة تبقى إدخالاً يدوياً للمعلم.
- دعم عدة سجلات لعدة مراحل وصفوف ومواد دون تعارض السجلات المتشابهة بين المراحل.
- لم يتم تعديل مركز المعلومات أو التخزين أو Edge Functions أو workflow.
