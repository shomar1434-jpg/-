# تقرير مراجعة سجلات المدير قبل الاستكمال

تم تنفيذ الجرد التدقيقي وفق قاعدة: تطوير الموجود بدل التكرار، وإنشاء غير الموجود فقط.

## قرارات الدمج وعدم التكرار
- الاتصالات الإدارية: تم تطوير سجل الوارد والصادر والتعاميم الموجود بدل إنشاء سجل جديد.
- الاجتماعات: موجود، وتم إبقاؤه وربطه بالمجموعة الإدارية.
- المجالس واللجان: موجود، وتم إبقاؤه وربطه بالمجموعة الإدارية.
- الخطة التشغيلية وملف الشواهد: موجود، وتم تطوير التسمية والربط.
- الصلاحيات: موجود، وتم إبقاؤه ضمن السجلات القيادية والتشغيلية.
- البيانات الشاملة: تم تطوير سجل البيانات الأساسية ليصبح سجل البيانات الشاملة.
- تقارير المشرفات: تم تطوير سجل زيارات المشرف المساند ليغطي تقارير المشرفات والمشرفين.
- الأداء الوظيفي: موجود، وتم فصله في مجموعة الأداء والمتابعة.
- التدقيق الداخلي: موجود، وتم إبقاؤه ضمن الجودة والحوكمة.

## سجلات أضيفت لعدم وجودها بشكل مستقل
- النشرات والتبليغات.
- التكليفات والوصف الوظيفي.
- الميزانية التشغيلية.
- دعم وتطوير الهيئة التعليمية.
- متابعة الهيئة التعليمية والإدارية.
- ضبط الوثائق.
- قياس اتجاه المتعلمين نحو المدرسة.
- الاختبارات الدولية.

## إعادة التقسيم المعتمدة
- السجلات الإدارية.
- السجلات القيادية والتشغيلية.
- سجلات الأداء والمتابعة.
- سجلات الجودة والحوكمة.
- السجلات التحليلية.
- سجلات مساندة محفوظة.

## الأرشيف
تم تحديث مجلدات أرشيف سجلات المدير لتطابق السجلات بعد إعادة التقسيم، مع بقاء الحفظ داخل المجلد الخاص لكل سجل عبر folderId.
