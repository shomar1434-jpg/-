تصحيح/تطوير C1 — تصنيف الوكيل

تم في هذه النسخة:
1) إضافة حقل «تصنيف الوكيل» في إدارة الحسابات داخل حساب المدير.
2) التصنيفات المدعومة:
   - وكيل الشؤون التعليمية
   - وكيل الشؤون المدرسية
   - وكيل شؤون الطلاب
   - وكيل عام / جميع السجلات
3) حفظ التصنيف محلياً بطريقة آمنة مرتبطة بالمدرسة ومعرف/بريد الوكيل حتى لا يعتمد العمل على تعديل قاعدة Supabase الآن.
4) عند دخول الوكيل، يتم تمرير/قراءة التصنيف وحفظه ضمن جلسة المستخدم.
5) داخل سجلات الوكيل يتم فلترة التصنيفات تلقائياً:
   - الشؤون التعليمية: تظهر سجلاتها + السجلات المشتركة.
   - الشؤون المدرسية: تظهر سجلاتها + السجلات المشتركة.
   - الوكيل العام: تظهر جميع السجلات.
6) نفس الفلترة تعمل عند فتح سجلات الوكيل من وضع المتابعة في حساب المدير.

ملاحظة:
لم يتم تنفيذ محرك التكليفات المدرسية بعد؛ هذه النسخة تجهز له بتثبيت تصنيف الوكلاء أولاً.
