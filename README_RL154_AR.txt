RL154 — تصحيح عام لتجاوز حصة التخزين في واجهة المدير

النطاق: جميع المدارس، بما فيها المدرسة التجريبية.
الملف المعدل: manager.html فقط.

المشكلة:
كانت بعض البيانات السحابية (الحسابات الفعلية والتكليفات) تُنسخ إلى localStorage ككاش. عند امتلاء الحصة كان setItem يرمي QuotaExceededError، فتظهر الواجهة وكأن تحميل الحسابات أو حفظ التكليف فشل رغم أن المصدر السحابي هو المصدر الرسمي.

التصحيح:
- إضافة حارس مبكر ومحدود لمفاتيح الكاش السحابي فقط.
- smartSchoolUnifiedOpsV2_users
- smartSchoolUnifiedOpsV2_users_session
- central_school_tasks_<school_id>
- عند امتلاء Local Storage تستخدم ذاكرة الصفحة ثم sessionStorage إن أمكن، ولا يُعاد رمي خطأ الحصة.
- لا يتم حذف أي بيانات محلية أو سحابية.
- لا يتم تغيير school_id أو الجلسات أو العضويات.
- لا تغيير في Supabase أو Edge Functions أو GitHub Actions.
- الحسابات والتكليفات تبقى معتمدة على المصدر السحابي.
