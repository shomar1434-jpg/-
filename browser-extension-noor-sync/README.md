# مساعد مزامنة الغياب من نور

1. افتح `chrome://extensions` وفعّل وضع المطور.
2. اختر «تحميل إضافة غير مضغوطة» وحدد هذا المجلد.
3. حدّث صفحة المنصة بعد تثبيت الإضافة.
4. افتح كشف الغياب اليومي في نور واترك التبويب مفتوحًا.
5. من دور وكيل/وكيلة شؤون الطلاب افتح «الغياب والمواظبة» واضغط زر المزامنة.

لا تفتح `popup.html` مباشرة؛ فهو نافذة داخلية للإضافة. بعد التثبيت الصحيح ستكتشفها المنصة تلقائيًا وتعرض «إضافة نور جاهزة» بدل زر التثبيت.

المزامنة لا تحفظ كلمات المرور ولا ترسل `school_id` من الإضافة. تتحقق وظيفة Supabase من جلسة المنصة والدور والمدرسة والطلاب، ثم تمنع تكرار الغياب لليوم نفسه.
