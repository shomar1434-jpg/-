تصحيح حاسم لتهيئة بوابة الموجه الصحي عند الدخول الطبيعي أو عبر تكليف دور كامل.

المشكلة:
كانت الصفحة تعتمد على window.onload = function(...). أي سكربت لاحق يستطيع استبدال هذا المعالج، وعند عدم تنفيذه يبقى كل من welcome-gate و welcome-dashboard مخفيين وتظهر الخلفية فقط.

التصحيح:
- استبدال الاعتماد على window.onload بتهيئة حتمية عبر DOMContentLoaded + addEventListener('load').
- التهيئة Idempotent ولا تعمل إلا مرة واحدة.
- إظهار بوابة الدخول الأصلية صراحة بعد اكتمال DOM.
- فصل كل خطوة تهيئة داخل try/catch حتى لا يمنع خطأ ثانوي ظهور واجهة الدخول.
- لا تغيير على school_id أو عزل المستخدمين أو تحقق التكليف الخادمي.
- لا SQL ولا Edge Function ولا تعديل Workflow.
